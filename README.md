# Piattaforma per la collezione di contenuti musicali

## DESCRIZIONE

Il software permette la collezione e la gestione collaborativa di materiale musicale (testi/audio/video/youtube).  
- Soltanto gli utenti autorizzati da un profilo admin potranno accedere.  
- Gli utenti hanno la possibilità di caricare/scaricare materiale musicale, commentare e annotare brani.

(Le password vengono hashate con SHA-256 prima di essere memorizzate nel database)


## TECNOLOGIE UTILIZZATE
- Linguaggio: JAVA
- UI Framework: JAVAFX
- UI Markup: FXML
- UI Styling: CSS
- Database: SQLite
- Testing: JUnit

## ARCHITETTURA
- Architetturale: MVC
- Design: DAO, Singleton, Singleton (variante lazy)
  




## NOTE
